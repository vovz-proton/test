# Работа с осциллографом

Если задача касается подключённого UNI-T UTD2102CL+, сначала прочитай
[docs/OSCILLOSCOPE.md](docs/OSCILLOSCOPE.md).
В инструкции указаны проверенный USB/VISA-адрес, способ чтения через PowerShell,
пути к установленному ПО и ограничения формата выгрузки.
Не переустанавливай уже работающий драйвер без диагностики.

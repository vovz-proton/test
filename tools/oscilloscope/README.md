# UNI-T UTD2102CL+ — просмотрщик для Windows

## Запуск

Подключите осциллограф по USB и откройте `Запустить осциллограф.cmd`.
Приложению нужны установленный NI-VISA x64 (`C:\Windows\System32\visa64.dll`)
и Python x64 с Tkinter. На этом компьютере они уже есть; лаунчер использует
Python runtime Codex в профиле пользователя.

## Управление

- CH1 и CH2 отображаются на отдельных графиках и опрашиваются непрерывно;
  фактическая скорость зависит от времени ответа осциллографа по USB.
- Цвета каналов: CH1 — бирюзовый, CH2 — жёлтый. Предыдущие положения трассы
  остаются в виде послесвечения и плавно исчезают за 0,5 секунды.
- Автомасштаб отключён. Вертикальная шкала каждого графика соответствует
  фактической шкале своего канала на осциллографе.
- У правого края графика тем же цветом, что и трасса, показывается среднее
  напряжение из измерения осциллографа; оно обновляется примерно дважды в секунду.
- Масштаб отображения графиков CH1 и CH2 по вертикали задаётся независимо в В/дел;
  изменение отправляется осциллографу и подтверждается чтением В/дел.
- Развёртка по времени задаётся общая для обоих каналов в с/дел — так устроен
  осциллограф.
- Колесо над графиком или селектором CH меняет только масштаб этого графика;
  Ctrl+колесо над графиком меняет развёртку времени. Колесо над общим селектором
  меняет время напрямую. Вверх — увеличение, вниз — уменьшение.
- «Считать сейчас» делает одиночное чтение, кнопка обновления останавливает
  и возобновляет поток.
- При выходе приложение восстанавливает исходные источник, формат и режим
  выгрузки осциллографа. Масштабы и развёртка, установленные пользователем,
  сохраняются на приборе.

## Замечание о форме волны

Прибор сообщает 800 точек в преамбуле, но в проверенном WORD-блоке отдаёт
1600 16-битных значений. Программа показывает все значения на интервале времени,
заданном преамбулой, и явно подписывает это расхождение на графике. Не используйте
этот график для точного измерения частоты до выяснения формата отсчётов данной
прошивки.

Подключение и команды описаны в `../../docs/OSCILLOSCOPE.md`.

## Автоподстройка В/дел

По умолчанию включена «Авто В/дел · 0,5 с». Программа накапливает максимальный
модуль напряжения каждого канала за полусекундное окно, учитывает измеренные
среднее и VPP, выбирает шкалу с запасом и отправляет её на сам прибор.
Гистерезис уменьшает переключения соседних диапазонов. При ручном изменении
В/дел автоподстройка отключается; её можно снова включить галочкой.
Развёртка времени остаётся ручной (Ctrl+колесо).

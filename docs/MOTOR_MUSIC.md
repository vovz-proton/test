# Музыкальная проба двигателя — 28.10.2026

Сборка: tools/build.ps1 -MusicTest -OutputDirectory build/music-test.
При включении один раз четыре восходящие ноты: до, ре, ми, фа
(262, 294, 330, 349 Гц), примерно по 300 мс, затем STBY=0.
Полношаговый режим; STEP идёт с удвоенной частотой ноты, DIR чередуется
после каждого спада STEP. Каждая пара: один шаг выдвижения и один обратно.
Чётное число импульсов на каждую ноту; суммарное заданное перемещение нулевое.
Возможна вибрация, отсутствие физического смещения не измерено.
CC прерывает пробу, FAULT активен. Концевик в этом режиме не используется
для остановки: амплитуда задания один полный шаг (~5 мкм по калибровке).
После завершения CS повторяет мелодию. При USB-загрузке мигает зелёный.
Загружено по USB, получена телеметрия после перезапуска; звук не оценён.

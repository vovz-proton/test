# tray_prank — программа в трее

Шутка для Windows: висит значком в системном трее и, пока включена, ловит
нажатие клавиши **«а»** — вместо неё «печатается» последовательность
**«хуйна»**. При выходе показывает окно **«Ну блин, не понравилось чтоли?»**.

Внешних библиотек не нужно: только Python 3 и WinAPI (через `ctypes`).
Проверено на Python 3.14, Windows 10/11 и Windows Server 2019.

## Как запустить

| Способ | Что делать |
|---|---|
| Двойной щелчок | `start_hidden.vbs` — запуск без окна консоли |
| Из консоли | `pythonw.exe tray_prank.py` |
| С отладкой | `run_console.bat` (или `python tray_prank.py --debug`) |

После запуска у часов появляется значок — красный кружок с белой «а».
Наведите курсор: подсказка «Хуйна-трей: нажми «а»».

## Как выключить

* правый клик по значку → **Выход** (появится прощальное окно);
* `stop.bat` — то же самое из консоли (`pythonw tray_prank.py --quit`);
* двойной щелчок по значку — включить/выключить перехват, не закрывая программу;
* правый клик → **Ловить клавишу «а»** — та же галочка в меню.

## Ключи командной строки

| Ключ | Смысл |
|---|---|
| `--text ТЕКСТ` | что печатать вместо «а» (по умолчанию `хуйна`) |
| `--no-question` | выйти молча, без прощального окна |
| `--quit` | попросить закрыться уже запущенную копию |
| `--quit-after N` | закрыться самому через N секунд (для проверки) |
| `--debug` | писать отладку в консоль |

Примеры:

```bat
pythonw tray_prank.py --text "привет"
pythonw tray_prank.py --quit
start "" pythonw tray_prank.py --quit-after 5
```

## Мелочи, о которых стоит знать

* Перехват идёт по **символу**, а не по позиции клавиши: в русской раскладке
  это «а», в английской — та же физическая клавиша «a». Сочетания с Ctrl/Alt/Win
  не трогаются, поэтому `Ctrl+A` («выделить всё») работает как обычно.
  Если нужна только русская «а» — в `tray_prank.py` оставьте
  `TRIGGER_CHARS = ("а",)`.
* Сама нажатая «а» гасится, поэтому в тексте появляется ровно `хуйна`.
  Чтобы получалось `ахуйна`, поставьте `SWALLOW_TRIGGER = False`.
* Перехват глобальный (низкоуровневый клавиатурный хук) — так и задумано,
  но некоторые антивирусы на такие хуки смотрят косо. Исходник открыт,
  при желании проверьте его сами.
* Если файла `tray_icon.ico` рядом нет, программа возьмёт системный значок.

## Автозапуск (по желанию)

`Win+R` → `shell:startup` → положить туда ярлык на `start_hidden.vbs`.

## Самопроверка

```powershell
powershell -ExecutionPolicy Bypass -File .\check_desktop.ps1
```

Скрипт сам создаёт окно с текстовым полем, нажимает «а» и проверяет, что в поле
появилось `хуйна`, затем проверяет прощальное окно и сохраняет его снимок
(`check_dialog.png`). Он ничего не печатает в чужие окна: если своё окно не
удалось сделать активным, проверка просто пропускается.
